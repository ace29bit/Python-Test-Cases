6. Find even and odd values

Question:
Write a function that checks whether each value is even or odd.

My answer:
def check(**a):
    for i in a:
        if a[i] % 2 == 0:
            print(i, "Even")
        else:
            print(i, "Odd")

check(a=10, b=15, c=22, d=31)


7. Find the highest value

Question:
Write a function that finds the highest value among the keyword arguments.

My answer:
def highest(**a):
    temp = 0
    for i in a:
        if a[i] >= temp:
            temp = a[i]
    print('Highest value ', temp)

highest(math=85, science=95, python=100, english=75)

Review note:
This works for the given positive numbers, but initializing temp to 0 fails if all values are negative. Initialize temp with the first value, or use a None check.


8. Find the lowest value

Question:
Write a function that finds the lowest value among the keyword arguments.

My answer:
def lowest(**a):
    print(min(a.values()))

lowest(a=45, b=20, c=65, d=10)

Review note:
This uses the built-in min() method. To solve without min(), initialize temp with the first value and compare the remaining values.

11. Separate positive and negative values

Question:
Write a function that separates positive and negative numbers into two different lists.

My answer:
def numbers(**a):
    pos = []
    neg = []
    for i in a:
        if a[i] >= 0:
            pos.append(i)
        else:
            neg.append(i)
    print('Poitive {}\nNegative {}'.format(pos, neg))

numbers(a=10, b=-5, c=20, d=-15, e=0)

Review note:
The original code appends i, which is the dictionary key. To store the numbers, append a[i]. Zero is neither positive nor negative.

13. Character frequency

Question:
Write a function that accepts keyword arguments containing characters and their frequencies, then prints the character with the highest frequency.

My answer:
def frequency(**a):
    temp = max(a.values())
    char = None
    for i in a:
        if a[i] < temp:
            temp = a[i]
            char = i
    print(char)

frequency(a=5, b=10, c=3, d=8)

Review note:
The comparison uses <, so it searches for a lower value. To find the highest frequency, use > and initialize temp using the first value (or an appropriate starting value).

ADDITIONAL CONCEPTS DISCUSSED
============================================================

Finding the smallest value without using min():

def lowest(**a):
    temp = None

    for i in a:
        if temp is None:
            temp = a[i]
        elif a[i] < temp:
            temp = a[i]

    print("Lowest value:", temp)

lowest(a=45, b=20, c=65, d=10)

Why the None check is needed:
Python cannot compare an integer with None. The first loop iteration assigns the first actual number to temp. Later iterations compare numbers with numbers.

TypeError:
A TypeError occurs when an operation is performed on an object of an unsuitable data type.
Example:
45 < None

This raises:
TypeError: '<' not supported between instances of 'int' and 'NoneType'
